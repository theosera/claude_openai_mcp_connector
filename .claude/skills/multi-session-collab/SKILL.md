# multi-session-collab — 所有と実行を分け、推論を観測より広げない

3 体 (Web 2 + CLI 1) で同じ vault を編集した実測から。**協働の事故は「内容」「帰属」
「経路」の 3 面で起き、対策がそれぞれ違う。**

## 規則

### 体制

1. **所有 = ① 内容の決定権 + ② 整合の最終責任。** 書き込みボタンを押す権利は所有では
   ない。**計器と実行は非所有者が担える** (例: CLI は測定と機械適用、Web 側が内容を所有)。
2. **分担の判断軸は「速い方」ではなく「できるかできないか」** (shell の有無・コンテキスト
   窓・経路の可否)。
3. **担当分離・手番の取り決めは、会話ではなくファイルに記録する。** 会話にしか無い
   取り決めは compaction とセッション終了で消え、**失われたら復元できない**。
4. **書く前の規約 3 つ**: 着手前に基点を取り直す (mtime だけでなく本文まで) /
   plan を出したら patch_id を宣言する / apply したら bytes と時刻を宣言する。

### 帰属

5. **帰属は当人の宣言でのみ確定する。** 時刻の近接 (28 秒 / 51 秒) は「同一の承認者」の
   証拠であって「同一の書き手」の証拠ではない。
6. **推論を観測より 1 段広げない。** 観測が言うのは「私ではない誰かが書いた」まで。
   「G4 が書いた」「未知の第三者がいる」はどちらも観測の外。

### レビュー

7. **他者レビューは礼儀ではなく構造である。** 型 A の誤り (観測は正しく推論が広すぎた) は
   **書いた本人には赤が出ない** — 実測 (G3 台帳 15 件): 型 A が最多の 6 件で、うち 5 件を
   他者が捕捉。全体でも自分の読解で捕まえたのは 3/15、機械検査 4、他者 8。
   **1 セッション運用では型 A が素通りする。**
8. **衝突は 1 点に絞って所有者判断へ。** 2 セッションが同機能を別々に実装しても、設計判断の
   衝突は 1 点だけだった — そこだけを質問にする。自分の版は branch に退避して消さない。

### 経路

9. **経路そのものが事故る (過失ゼロでも)。** 回答が 6 時間 10 分届かず、受け手は「未決」と
   書いた — どちらの過失でもなく、ファイルが経路上で落ちた。**過失が無くても事故は事故として
   台帳に載せる。** 「回答を出した先が受け取ったかは、出した側からは確かめられない」 —
   **完了は受け手の次の文書で確認する** (→ 検査の形は `handoff-block-integrity`)。

### compaction 生存

10. **何が消えるかは推測せず実測に従う** (2026-08-16 実測): プロジェクトの CLAUDE.md は
    ハーネスが毎回再注入する。**消えるのは skill の中身・settings.json・会話上の取り決め。**
    - /compact の**前**: セッション固有の取り決め・進行状態・宣言済みの数値をファイルへ退避する
    - 復帰**直後**: settings.json を読む / 継続作業の skill をロードし直す (**「ロードした
      記録」はロードではない**) / 再開タスクを各発火表に改めて照合する

## 事故録 (すべて実測)

- **28 秒の近接から「親を触ったのは CLI」と帰属** (実際は G4)。同型を別セッションも
  同日に踏んだ (「G4 が書いた」— 実際は近接だけ)。**確定させたのはどちらも当人の宣言。**
- **2 セッションが同じ機能を別 branch で実装** (2026-08-16 22:42)。差分を取ると設計衝突は
  「walk の一覧に無いノートの扱い」1 点だけ → その 1 点を所有者に質問し、勝った設計に
  逆検証を付けて統合。
- **compact 前の退避を 2 セッションが独立に実施** (各自の退避ファイルへ)。退避しなかった
  項目 (会話上の合意) は要約後に消えることが繰り返し確認されている。

## アンチパターン

- 「速い方がやる」で分担を切る (正しい軸は「できるかできないか」)
- 時刻の近接・書式の癖から帰属を推定して記録に書く (確定は当人の宣言だけ)
- 退避なしの /compact (会話にしか無い取り決めは要約を生き延びない)
- 所有者の領域を善意で直す (整合の最終責任が二重化する。見つけた問題は所有者へ申告する)
